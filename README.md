# Unfog Panda – Datenschutzerklärung

Nur die beiden Rechtstexte der Android-App **Unfog Panda**, damit der Play
Store eine öffentlich erreichbare URL hat. Der Quellcode der App liegt in
einem eigenen, privaten Repository.

Veröffentlicht über GitHub Pages:

- https://enzodeluxe.github.io/unfogpanda-datenschutz/datenschutz.html
- https://enzodeluxe.github.io/unfogpanda-datenschutz/privacy.html

Die Dateien sind Kopien aus `store/` des App-Repositorys. Wird dort etwas
geändert, muss es hier nachgezogen werden.
